ARGENTINA RENT CALCULATOR

Upload the complete contents of this folder to:
Calculation/Rent/
in your GitHub repository.

Then open:
https://ultrasounddk.github.io/Calculation/Rent/

The app downloads:
- Blue Dollar Compra and Venta from DolarAPI.
- IPC from Argentina's official Time Series API using the INDEC national CPI series.

Both sources can fail temporarily. All fields remain editable manually.
The three monthly IPC percentages are ADDED, not compounded, as requested.
